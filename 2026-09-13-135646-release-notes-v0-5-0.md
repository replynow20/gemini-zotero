# Gemini Zotero v0.5.0 Release Notes

**Release Date**: 2026-09-13

## What's New

### Zotero 10 Compatibility

- Extended the supported Zotero range to versions 7 through all 10.x releases.
- Migrated Markdown and template file dialogs to the Zotero Toolkit `FilePicker` wrapper required by the Firefox 140 platform.
- Updated the Services type declaration from the removed JSM path to the current ESM path.

### Model Updates

- Updated the selectable text models to `gemini-3.8-flash` and `gemini-3.7-flash`.
- Added separate image-model selection for `gemini-3-pro-image`, `gemini-3.1-flash-image`, and `gpt-image-2`.
- Automatically migrates retired text preview models and `gemini-3-pro-image-preview` to current defaults.

### OpenAI-Compatible Image Generation

- Added GPT Image generation through the OpenAI-compatible `/v1/images/generations` endpoint.
- Kept PDF analysis and prompt generation on Gemini while routing only image generation through the selected image provider.
- Added retries for transient API and download errors, support for base64 and URL responses, and a medium-to-low quality fallback at `1536x1024`.
- Added a Gemini-specific 2K-to-1K fallback without applying OpenAI quality parameters to Gemini requests.

### Gemini Files API

- Corrected resumable upload URL construction for official and proxied Gemini roots.
- Corrected file-state polling paths and now rejects failed or unexpected terminal states.

## Configuration Notes

The plugin currently has one API Key and one API Base URL shared by text and image requests. Leaving Base URL empty uses the official Gemini API and therefore supports Gemini image models only. To use `gpt-image-2`, configure a gateway that accepts the same credential and exposes both Gemini `/v1beta` endpoints and OpenAI-compatible `/v1` image endpoints under the same root.

Text generation parameters such as Temperature, Top P, Top K, and Max Output Tokens do not control image size or quality.
